# Мират — первый этап, отчёт к 14 сентября

Подготовлено 13 сентября 2026 года. Объём: каркас интерфейса, wireframes,
черновик API. Это демонстрационный прототип с вымышленными данными.

## Запуск и макеты

Из `frontend/`: `npm ci`, затем `npm run dev`. Откройте `/admin/login`
на адресе, который напечатает Vite. Все пять интерактивных wireframes доступны
через боковое меню; они являются макетами для отчёта и обсуждения с командой.

| Маршрут frontend | Содержание и проверка |
| --- | --- |
| `/admin/login` | Email, пароль, будущая кнопка входа и явный переход к демо. Поля отключены, пароль не собирается. |
| `/admin` | Карточки, переключение пользователей/событий/заказов, локальный поиск и пустой результат. |
| `/organizer/campaigns/new` | Событие, название, тип/величина скидки, даты, лимит, тип билета; проверка полей и локальный предпросмотр. |
| `/organizer/analytics` | Макеты показателей, продаж по дням/типам, кампаний и посещаемости; фильтры явно отключены. |
| `/organizer/history` | Фильтр четырёх статусов событий и отдельный пример хронологического журнала. |

## Границы и совместная работа

Код Мирата: `frontend/src/mirat/`. Точка подключения: `frontend/src/main.jsx`.
Главная страница Анвара сохранена. Пока используются обычные ссылки и точное
сопоставление путей, без новой зависимости роутера. При появлении общего роутера
перенести эти пять маршрутов в него. Production-хостинг должен возвращать
`index.html` для frontend-путей; `/api` направлять к Django. Frontend `/admin`
и Django Admin на backend-порту — разные интерфейсы.

Все демо-страницы доступны без входа и не дают реальных прав. Запросов к API,
сохранения кампаний, генерации QR/PDF и реальных агрегатов в этом этапе нет.
Следующий этап подключит общий login/session и защиту маршрутов по ролям;
проверка доступа к данным всегда должна выполняться и на backend.

В `API_CONTRACT.md` добавлены предложения по запросам, ответам, доступу,
валидации для Admin, Analytics, Promo Codes и истории. Все новые API остаются
`planned`; реализованное API описано в `BACKEND_MVP_API.md`. Согласование с
Нурсатом, Айжан и Анваром остаётся командным шагом, не считается выполненным.
